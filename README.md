# UNI-RAG Agent

A multimodal Retrieval-Augmented Generation (RAG) project that brings together document analysis, segmentation, neural processing, and multimodal retrieval components.

This repository is maintained by [Shriyansh Tummala](https://github.com/2shriyansh-ai) as a portfolio presentation of a four-person academic group project.

## Project Overview

UNI-RAG Agent explores a modular pipeline for processing and retrieving information from multiple data formats. The repository groups the work into analysis, segmentation, neural, and multimodal RAG components.

## Repository Structure

- **Analyst/** — Analysis-related components
- **Segmentation/** — Segmentation pipeline
- **neural - Copy/** — Neural-processing experiments
- **sih_multimodal_rag/** — Multimodal RAG submodule
- **sih_multimodal_rag - Copy (2)/** — Multimodal RAG implementation copy

## Key Areas

- Multimodal information processing
- Document and data analysis
- Segmentation workflows
- Neural-processing components
- Modular experimentation and integration
